### 3. HƯỚNG DẪN VẬN HÀNH DÀNH CHO OWNER

1. **Khởi chạy môi trường phát triển (Dev Mode):**
   ```powershell
   npm run dev
   ```
2. **Kiểm tra sức khỏe hệ thống định kỳ (Health Check & Verification):**
   ```powershell
   node scripts/verify-g30.mjs
   ```
3. **Sao lưu hệ thống trước khi cấu hình lớn (Manual Snapshot):**
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/snapshot-backup.ps1 -Label "manual-backup"
   ```
4. **Phục hồi cơ sở dữ liệu khi cần thiết:**
   - Dữ liệu sao lưu luôn đi kèm file `.json` manifest chứa mã băm SHA-256.
   - Thao tác khôi phục qua `DatabaseClient.restoreBackup()` tự động tạo bản sao lưu phòng ngừa trước khi thay thế tệp cơ sở dữ liệu.
